# StockSense

โปรแกรม Windows ช่วยตัดสินใจซื้อ/ขายหุ้นสหรัฐ: ดึงข้อมูลจริงจากหลายแหล่ง คิดคะแนนด้วยกติกาตายตัว แล้วให้ AI อธิบายเป็นภาษาง่ายๆ

> ข้อมูลนี้ช่วยประกอบการตัดสินใจเท่านั้น ไม่ใช่คำแนะนำการลงทุน

## ปุ่ม 4 ปุ่ม

| ปุ่ม | ทำอะไร |
|---|---|
| วิเคราะห์ซื้อ | ให้คะแนน 6 เรื่อง รวมเป็น % ความน่าซื้อ |
| วิเคราะห์ขาย | คะแนนเดียวกันกลับด้าน + กำไรขาดทุน + เช็กเหตุผลที่ซื้อ + สัญญาณอันตราย |
| วิเคราะห์งบล่าสุด | อ่านงบไตรมาสล่าสุดและข่าวประกาศผลประกอบการจาก SEC แล้วสรุป |
| ตรวจพอร์ต | ดูทั้งพอร์ตรวมกัน: คะแนนสุขภาพ เงินกองอยู่ตัวไหน หุ้นที่ซ้อนอยู่ในกองทุน (VOO/QQQ/VTI) จัดอันดับตัวที่น่ากังวล กำไรเป็นบาทแยกเป็นส่วนราคาหุ้นกับส่วนค่าเงิน และวันประกาศงบใน 30 วัน |
| เงื่อนไขเปลี่ยนใจ | ตั้งไว้ต่อหุ้นที่ถือ (ราคาหลุด / ขาดทุนเกิน % / น้ำหนักในพอร์ตเกิน % / งบแย่กว่าคาด) โปรแกรมตรวจให้ตอนเปิดและขึ้นแถบเตือนสีแดง ไม่ขายให้เอง |
| นักวิเคราะห์พูดว่าอะไร | กล่องในหน้าวิเคราะห์: สรุปว่านักวิเคราะห์ส่วนใหญ่แนะนำซื้อ/ถือ/ขาย + นักวิเคราะห์รายคนที่พบชื่อในข่าว 14 วัน พร้อมลิงก์ข่าวต้นทาง (ไม่เดาชื่อ ไม่บอกความแม่น) |

ปุ่มวิเคราะห์ซื้อจะบอกด้วยว่า ถ้าซื้อเพิ่ม $500 ตัวนั้นจะกลายเป็นกี่ % ของพอร์ต

### คะแนนสุขภาพพอร์ต

60% = สุขภาพของหุ้นที่ถือ (100 − คะแนนวิเคราะห์ขาย ถ่วงตามขนาดที่ถือ) + 40% = การกระจายความเสี่ยง (ตัวที่หนักสุดไม่เกิน 20% ของพอร์ต = เต็ม 100 ลดลง 2.5 คะแนนต่อทุก 1% ที่เกิน)
สัดส่วนหุ้นที่ซ่อนอยู่ในกองทุนเป็นค่าประมาณจากตารางใน `stocksense/portfolio_check.py` (ปรับตามราคาหุ้นทุกวัน) กองทุนที่ไม่มีในตารางนับว่ากระจายตัวแล้ว

## ข้อมูลมาจากไหน

| ข้อมูล | แหล่ง | ต้องใช้คีย์ |
|---|---|---|
| ราคาและกราฟ | Yahoo Finance | ไม่ต้อง |
| งบการเงิน เอกสารบริษัท | SEC EDGAR (ทางการ) | ไม่ต้อง |
| อัตราแลกเปลี่ยน | open.er-api.com | ไม่ต้อง |
| ข่าว นักวิเคราะห์ ผลประกอบการ P/E | Finnhub (ฟรี) | ต้อง |
| คำอธิบายภาษาไทย | Gemini (ฟรี) | ต้อง |

## % คิดยังไง

แต่ละเรื่องได้คะแนน 0–100 จากกติกาใน `stocksense/scoring.py` (AI เปลี่ยนคะแนนไม่ได้) แล้วถ่วงน้ำหนัก

| เรื่อง | น้ำหนักตอนซื้อ | น้ำหนักตอนขาย |
|---|---|---|
| งบการเงิน | 25 | 15 |
| ราคาถูกหรือแพง | 20 | 20 |
| ผลประกอบการ | 15 | 15 |
| นักวิเคราะห์ | 15 | 10 |
| ข่าว | 10 | 15 |
| กราฟราคา | 15 | 25 |

เรื่องที่ไม่มีข้อมูล (เช่นกองทุนดัชนีไม่มีงบ) จะถูกตัดออก แล้วถ่วงน้ำหนักเรื่องที่เหลือใหม่

## ที่เก็บข้อมูล

ทุกอย่างอยู่ใน `%APPDATA%\StockSense` (คีย์เข้ารหัสด้วย Windows, พอร์ต, ประวัติ, แคช) ติดตั้งทับเวอร์ชันใหม่แล้วไม่หาย

## สำหรับนักพัฒนา

```
pip install -r requirements.txt pytest
python -m pytest -q tests
python -m stocksense            # เปิดโปรแกรม
python -m stocksense --selftest # ทดสอบแบบไม่ใช้เน็ต
```

ทุกครั้งที่ push ขึ้น `main` GitHub Actions จะทดสอบ สร้าง `.exe` + ตัวติดตั้ง แล้วปล่อยที่หน้า Releases
